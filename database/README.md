# Datenmodell

Dieses Projekt besitzt keine Serverdatenbank und keine SQL-Migrationen. Die maßgeblichen Datenmodelle/Validatoren liegen in `web/app.js` und `web/feature-store.js`. Sie sind vollständig im Export enthalten. Persönliche Datensätze liegen im Browser und sind nicht Bestandteil des Quellcodeexports. Siehe die Export-README für die separate JSON-Sicherung und den Domainwechsel.
